# Findecore

Landing page for **Findecor**, an AI assistant that helps you find, style and furnish your home.

Live: [findecore.vercel.app](https://findecore.vercel.app)

## Sections

- **Showcase** with a typing animation and a product video
- **How it works**
- **Features**: AI-powered personalization, room and furniture matching, custom furniture generation and smart price comparison
- **FAQ**
- **Call to action** and footer

## Tech stack

- Next.js (App Router) and TypeScript
- Tailwind CSS and shadcn/ui components (Radix UI)
- Framer Motion for animations
- Three.js with React Three Fiber and Drei for 3D

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Build for production |
| `npm start` | Run the production build |
| `npm run lint` | Run ESLint |
